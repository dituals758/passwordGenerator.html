# Password Generator PWA

Быстрое создание надёжных паролей. Полностью офлайн — ваши данные остаются на устройстве.

## Установка

### На смартфон (PWA)
1. Откройте сайт в браузере Chrome/Safari
2. Нажмите «Установить приложение» в футере
3. Приложение появится на домашнем экране

### Локально
```bash
git clone https://github.com/dituals758/passwordGenerator.html.git
cd passwordGenerator.html
# Откройте index.html в браузере
```

## Как пользоваться

### Режим «Пароль»
Генерирует строку из случайных символов. Настраиваемые параметры:
- Длина от 8 до 32 символов
- Наборы символов: строчные, заглавные, цифры, спецсимволы
- Исключение похожих символов (0 O 1 l I |)
- Исключение повторов подряд
- Только уникальные символы

### Режим «Фраза»
Генерирует серию случайных слов (например: Correct-Horse-Battery-Staple).
- От 3 до 8 слов
- Заглавная буква в каждом слове
- Опциональная цифра в конце

**Парольная фраза** — это серия случайных слов, разделённых дефисом. Преимущество: длинная последовательность, которую легко запомнить, но крайне сложно подобрать brute-force'ом. Энтропия растёт экспоненциально с каждым добавленным словом.

### Горячие клавиши
| Клавиша | Действие |
|---------|----------|
| `Пробел` | Создать и скопировать пароль |

### Дополнительно
- **История** — последние 20 паролей сохраняются на устройстве
- **Экспорт** — сохранение истории как CSV-файл
- **Поделиться** — отправка пароля через нативный шаринг (если поддерживается)
- **Тема** — автоматическое переключение тёмной/светлой темы

### Безопасность (CSP)
```
default-src 'self'           # Только собственные ресурсы
style-src 'self' 'unsafe-inline'  # Стили (инлайн для скелетона)
script-src 'self'            # Скрипты только с своего домена
img-src 'self' data:         # Изображения
connect-src 'self'           # Сетевые запросы
manifest-src 'self'          # Манифест
```

### Service Worker (кэширование)
Стратегия: **Cache First** с.network fallback.
1. При установке все статические файлы кэшируются
2. При запросе сначала ищем в кэше
3. Если нет — загружаем из сети и кэшируем
4. При офлайне — отдаём кэшированные файлы
5. При обновлении — показываем диалог, при согласии обновляем

### Генерация паролей
- Используется `crypto.getRandomValues()` — криптографически стойкий PRNG
- Алгоритм отсечения (rejection sampling) для исключения bias
- При `onlyUnique`: Fisher-Yates shuffle + замена для гарантированного покрытия наборов
- При `excludeRepeating`: повторное перемешивание до 100 попыток

### Strength Meter
Энтропия рассчитывается как `log2(poolSize) × length`:
- < 40 бит: Слабый
- 40–60 бит: Средний
- 60–80 бит: Надёжный
- > 80 бит: Отличный

Для парольных фраз: `log2(679 слов) × количество слов`.
